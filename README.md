## 💻 Sobre o Projeto

O **StudyTask** é uma plataforma de organização de tarefas desenvolvida com o objetivo de auxiliar na organização de atividades de estudo e trabalho.

A aplicação permite criar e acompanhar tarefas, definindo informações como **prazo** e **nível de prioridade**, proporcionando uma forma simples e intuitiva de visualizar atividades pendentes e concluídas.

O projeto foi desenvolvido como parte dos estudos de desenvolvimento Front-end, com foco na aplicação prática de conceitos de **HTML, CSS e JavaScript**.

---

## ⚙️ Funcionalidades

* [x] Criação de tarefas
* [x] Definição de prazo para tarefas
* [x] Definição de nível de prioridade
* [x] Limite de até 30 tarefas
* [x] Visualização de tarefas pendentes
* [x] Visualização de tarefas concluídas
* [x] Gerenciamento do status das tarefas

## 🛠️ Tecnologias Utilizadas

* **HTML5** — estrutura e organização da aplicação
* **CSS3** — estilização e layout
* **JavaScript** — lógica e interatividade
* **Bootstrap** — componentes e estilização da interface

## 📖 Aprendizados

Durante o desenvolvimento do projeto, foram praticados conceitos como:

* Estruturação de páginas com HTML5

* Manipulação do DOM com JavaScript
* Criação de elementos dinamicamente
* Manipulação de eventos
* Organização e validação de dados das tarefas
* Utilização de componentes do Bootstrap
* Desenvolvimento de uma interface voltada para usabilidade
